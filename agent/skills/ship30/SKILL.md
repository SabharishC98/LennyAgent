# Ship 30 for 30 Essay Principles

## Description
This skill encodes the core principles of writing a Ship 30 for 30 atomic essay based on grounded evidence from Lenny's transcripts.

## Principles
1. **Strong hook:** Start with an engaging, bold statement or question to grab attention.
2. **One idea:** Focus the entire essay on a single, clear, cohesive thesis.
3. **Short paragraphs:** Keep paragraphs to 1-3 sentences for readability.
4. **Useful headings:** Break up the text with descriptive, scannable headers.
5. **Sparing bold:** Use bold text only to emphasize key insights, not entire sentences.
6. **One actionable takeaway:** End the essay with a clear, specific, actionable conclusion for the reader.

## Constraints
- Length: Target is ~1,250 words. Strict validation: 1,150–1,350 words.
- All factual claims MUST trace to retrieved chunk evidence.
- Include a source list at the end.
- If evidence is insufficient, explain the limitation instead of fabricating support.
